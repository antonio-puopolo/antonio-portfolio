# Antonio Puopolo - Real Estate Portfolio

Professional portfolio website for Antonio Puopolo, Lead Agent at Hicks Team, Place Estate Agents Camp Hill.

## Features

- ✅ Responsive design (mobile, tablet, desktop)
- ✅ Hero section with clear CTA
- ✅ About section highlighting expertise
- ✅ Recently sold properties showcase
- ✅ Current listings display
- ✅ Client testimonials
- ✅ Lead capture form with localStorage
- ✅ Professional footer with contact info

## Tech Stack

- React 18
- Tailwind CSS
- Vite
- Lucide Icons

## Setup on Replit

1. Create a new Replit project
2. Upload all files from this directory
3. Run `npm install` to install dependencies
4. Run `npm run dev` to start the development server
5. Deploy to get a public URL

## Lead Capture

Form submissions are stored in localStorage. To view captured leads:

```javascript
// In browser console
JSON.parse(localStorage.getItem('leads'))
```

## Customization

- Colors: Edit `tailwind.config.js` for brand colors
- Content: Edit `src/App.jsx` for text and images
- Images: Replace Unsplash URLs with actual property photos
